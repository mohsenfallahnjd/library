# Library — milestones

Each milestone fits roughly two long blocks (2–4 hours).

- [ ] **0. Scaffold.** In this folder run `bunx create-next-app@latest .` (TypeScript, Tailwind, App Router). Commit.
- [ ] **1. Links.** Add an article/site by URL, auto-fetch its title, list items. Store in Postgres with Drizzle.
- [ ] **2. Status, tags, filters.** Change status, add tags, filter the list by kind / status / tag, simple search by title.
- [ ] **3. PDF books.** Upload a PDF to Vercel Blob, open it in a PDF.js reader view, save the last page and resume there.
- [ ] **4. Phone.** Make it an installable PWA, fix the layout for phone width, add a quick way to save links from the phone.
- [ ] **5. Deploy.** Deploy to Vercel, add a simple password, use it for one full week of real reading.
- [ ] **6. Stretch.** Pick one: highlights and notes per item exported to Obsidian as Markdown; a reflowed text view for PDFs; a "reading streak" stats page.
